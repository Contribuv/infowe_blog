评论区「左右对话」Demo v2

规则和微信一致：回复出现在被回复者的另一侧。两人对话自动形成 A 左 → B 右 → A 左 → B 右 的一来一回。每条都保留原有的 IP 归属地与 UA 信息。

侧别规则：根评论 = 左；层数 1（直接回复根）= 右；层数 2 = 左；层数 3 = 右……即奇数层右、偶数层左，等价于「回复落在对象对侧」。同一人连续发言会保持在同一侧（和你回复谁有关）。多人场景靠现有的 @某人 标记区分对象。
也可以直接拉窄窗口 / F12 手机模式看真实响应式

这次请重点看：① 两人多轮时，左右交替是否清楚、像对话；② 三人场景里同侧出现不同作者（示例 2 的豪子与 Lan 分居右/左）是否能靠 @ 与头像分辨；③ 每条的 IP 归属地 + UA 是否齐全都保留、且不会抢正文；④ 长段落气泡占 72%（移动 86%）宽是否好读；⑤ 楼层卡片是否仍需要（去掉了会变成纯聊天流）。
